# Voice Avatar

Голосовой ИИ-ассистент с визуальным аватаром и поддержкой распознавания и синтеза речи.
Проект используется как центральный узел управления системой умного дома и личными сервисами.

## 📌 Описание проекта

Voice Avatar — это голосовой помощник с аудиовизуальным интерфейсом,
который принимает голосовые команды, обрабатывает их и выполняет действия
через подключённые API и сервисы.

Проект был разработан как экспериментальная платформа для управления
умным домом и другими проектами с помощью голоса.

## 🎯 Возможности

- Распознавание русской речи (STT)
- Озвучивание ответов (TTS)
- Визуальный аватар с отображением статуса обработки
- Голосовое управление внешними сервисами
- Модульная архитектура для добавления новых команд

## 🧠 Используемые технологии

- Python
- Vosk (Speech-to-Text, русская модель)
- Аудиообработка
- Работа с внешними API
- Монолитная архитектура
- Gif (временное решение)

## 🧱 Структура проекта

- `main.py` — точка входа приложения
- `Avatar.py` — логика визуального аватара
